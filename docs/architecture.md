# VasukiPublication — Architecture Overview

VasukiPublication is the public web presentation and reader application for books generated by **VasukiSquare**.

```
┌─────────────────────────────────────────────────────────────┐
│                        VasukiSquare                         │
│   (LLM Research Engine • Layout Planner • Book Generator)   │
└──────────────────────────────┬──────────────────────────────┘
                               │ Persists structured documents
                               ▼
┌─────────────────────────────────────────────────────────────┐
│                      MongoDB Database                       │
│    Collections: books • pages • covers • ads                │
└──────────────────────────────┬──────────────────────────────┘
                               │ Reads public published content
                               ▼
┌─────────────────────────────────────────────────────────────┐
│                      VasukiPublication                      │
│   (Next.js App Router • React Server Components • Reader)   │
└─────────────────────────────────────────────────────────────┘
```

---

## 1. System Relationship

- **VasukiSquare (Authoring Engine)**: Generates technical and non-fiction books through automated LLM research, editorial planning, layout calculation, and structured block generation. It stores the final publication artifacts directly into MongoDB.
- **MongoDB (Canonical Persistence)**: Acts as the single source of truth. Contains complete book metadata, individual chapter pages, cover styling parameters, and native advertisement campaigns.
- **VasukiPublication (Public Platform)**: Reads directly from MongoDB. It provides high-performance browsing, search, catalog filtering, book detail pages, and an isolated, responsive A4 reader without depending on PDF files.

---

## 2. Architectural Layers

### 2.1 Database & Connection Pooling (`lib/db/`)
- Utilizes the official `mongodb` Node driver.
- Employs a global client cache in development to eliminate socket exhaustion during Next.js Fast Refresh.
- Implements resilient singleton connection lifecycle for serverless environments (Vercel).

### 2.2 Repository Layer (`lib/repositories/`)
- Isolates MongoDB queries behind strongly typed async functions.
- Enforces publication constraints (`publication.status === 'published'` and `publication.visibility === 'public'`).
- Enforces pagination defaults (20 items, max 50) and lightweight projections so catalog listings never load bulk page data.

### 2.3 Compatibility Layer (`lib/vasuki/`)
- `book-schema.ts`: Zod validation schemas reflecting VasukiSquare's schema version 1.
- `render-tokens.ts`: Publication design tokens (Euclid Circular A, JetBrains Mono, Brand Green, Deep Teal, A4 proportions).
- `icon-map.ts`: Normalization mapping from persisted icon names to Lucide components.
- `sanitization.ts`: Security boundary sanitizing pre-rendered HTML before rendering.

### 2.4 Security Primitives (`lib/security/`)
- `url.ts`: Protocol verification and hostname extraction preventing `javascript:` and phishing attacks.
- `crypto.ts`: Constant-time comparison for authentication tokens.
- `html.ts`: Tag and attribute sanitization engine.

---

## 3. Server vs. Client Boundaries

- **Server Components (Default)**:
  - Catalog listings, book overview pages, static metadata, and OpenGraph generators execute purely on the server.
  - Zero database client code or secrets are sent to the browser.
- **Client Components (`"use client"`)**:
  - Saved books drawer (localStorage synchronization).
  - Search modal interactivity and keyboard shortcuts (`Cmd+K`).
  - Reader navigation controls (keyboard arrows, zoom, fullscreen mode).

---

## 4. Route Hierarchy

- `/` — Homepage: Hero, Featured Showcase (pinned 1..5), Recent Publications, Category Browse, Native Banner Ads.
- `/book/[slug]` — Book Details: Cover view, synopsis, chapter outline, metadata, start reading button, JSON-LD structured data.
- `/book/[slug]/opengraph-image` — Dynamic 1200x630 social preview generation using `ImageResponse`.
- `/book/[slug]/read` — Interactive Reader: Isolated A4 page viewer, linked-list page progression, zero ads.
- `/saved` — Saved Books: Local bookmarks and offline reading queue.
- `/sitemap.xml` — Dynamic SEO sitemap.
- `/robots.txt` — Search engine crawler instructions.
- `/api/books` — Public JSON catalog endpoint.
- `/api/search` — Public search endpoint.
