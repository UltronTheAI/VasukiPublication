# VasukiPublication — Book & Cover Rendering Architecture

VasukiPublication renders technical books and cover artwork directly from MongoDB structured data and pre-rendered HTML components without relying on PDF files.

---

## 1. The Zero-PDF Philosophy

Traditional digital publishing platforms force users to download large static PDF files or use sluggish PDF.js canvas viewers. VasukiPublication replaces this entirely with a modern web-native reading experience:

- **Ultra-Fast Streaming**: Book pages load incrementally on demand via pagination or linked-list traversal (`previous_page_id` / `next_page_id`).
- **Semantic DOM Elements**: Text, headings, code blocks, tables, and callouts are rendered as true HTML elements, allowing native text selection, searching, copying, and screen reader accessibility.
- **Dynamic Syntax Highlighting**: Code snippets retain language metadata and structure.
- **Zero PDF Processing Overhead**: No PDF parsing, no font embedding issues, and no heavyweight client-side PDF decoders.

---

## 2. Structured Content vs. Persisted HTML

VasukiSquare persists two representations in each page document:

1. **Structured Data (`Page.content`)**:
   - Machine-readable block models (`CodeBlock`, `TableBlock`, `CalloutBlock`, `TerminalBlock`, `TocBlock`, etc.).
   - Enables future dynamic transformations, alternative themes, or text-to-speech rendering.
2. **Pre-rendered HTML (`Page.html`)**:
   - Acts as a high-performance markup cache generated by VasukiSquare's layout engine.
   - Passed through `lib/vasuki/sanitization.ts` to guarantee absolute protection against stored XSS before rendering in the browser.

---

## 3. Style & Design Token Isolation

The website shell and the book reader utilize separate, isolated design languages:

| Context | Design Source | Color Palette / Aesthetic |
| :--- | :--- | :--- |
| **Website Shell** | `DESIGN.md` | Ink `#171717`, Canvas `#ffffff`, Vercel-inspired subtle hairline borders, vivid mesh gradient accents. |
| **Book Pages** | `lib/vasuki/render-tokens.ts` | Brand Green `#00ed64`, Deep Teal `#001e2b`, Euclid Circular A, JetBrains Mono, structured A4 canvas. |

### Isolation Rules
- Book reader pages render inside a scoped container (`.vasuki-page-container`).
- Global CSS styles from `globals.css` must never override page-specific fonts, line heights, or colors.
- Chapter themes alternate according to editorial rules (e.g. Chapter 1 light, Chapter 2 dark) without affecting the website navigation bar or footer.

---

## 4. Reusable Dynamic Cover Renderer (`CoverPreview`)

Cover artwork is rendered directly from `Book` and `Cover` metadata without raster PDF screenshotting:

- **Art-Directed Composition**: Supports `asymmetric_left`, `centered_editorial`, `large_typography`, `bottom_weighted`, `framed_technical`, `icon_led`, `split_panel`, and `minimal_slate`.
- **Background Styling**: Adapts to `solid_light`, `subtle_grid`, `layered_mesh`, `radial_glow`, `split_tone`, and `minimal_slate`.
- **Geometric Motifs**: Renders lightweight SVG geometric patterns (`database_nodes`, `circuit_grid`, `structural_rings`, `abstract_matrix`).
- **Iconography**: Resolves Lucide icons dynamically via `lib/vasuki/icon-map.ts`.
- **Deterministic Fallbacks**: When older records lack complete cover documents, the renderer falls back deterministically to book metadata (title, category, author, and Brand Green / Deep Teal tokens).

---

## 5. Dynamic OpenGraph Social Previews (`opengraph-image.tsx`)

Each publication generates a dynamic 1200x630 social card via Next.js `ImageResponse` from `next/og`:

- **Zero PDF / Browser Screenshots**: Renders pure JSX / SVG layout on edge / server.
- **Visual Parity**: Reconstructs the publication's palette, typography, author, and cover identity.
- **Performance**: Cached automatically by Next.js metadata routes without requiring image storage in MongoDB.

---

## 6. A4 Geometry & Responsive Scaling

Every page adheres to standard A4 proportions (Width to Height ratio of `210 / 297 ≈ 0.7071`):

- On desktop viewports, the reader presents a centered A4 canvas with proportional scaling or side-by-side spread view.
- On mobile viewports, the reader preserves inner block padding and scales content gracefully while keeping layout anchors intact.

---

## 7. Monetization & Content Integrity

To maintain an uncompromised reading experience:
- **No Ads Inside Pages**: Advertisements are strictly prohibited from appearing within reader viewports or interrupting chapter flows.
- **Clean Focus**: The reader provides distraction-free reading with simple navigation controls, reading progress indicators, and bookmarking.
