# VasukiSquare Book Reader Architecture

This directory is reserved for components responsible for rendering books generated by VasukiSquare.

## Core Architectural Invariants

1. **Design System Isolation**:
   - The **Website Shell** (navigation bar, search modals, book grid, saved drawer, footer) follows `DESIGN.md` (Vercel-inspired stark ink & mesh gradients).
   - The **Book Reader** (covers, chapters, A4 pages, code blocks, tables, callouts) strictly renders using **VasukiSquare's Persisted Book Design Tokens** (`lib/vasuki/render-tokens.ts`).
   - Do **NOT** merge website global CSS styles with book page styles. Keep book container styles scoped and isolated.

2. **Zero PDF Dependency**:
   - Books are NOT rendered from PDF files.
   - All content is delivered from MongoDB as structured data (`PageContent`, `ContentBlock` unions) and/or pre-rendered, sanitized HTML blocks (`Page.html`).

3. **A4 Fixed Aspect Ratio**:
   - Book pages must scale proportionally maintaining standard A4 geometry (210mm x 297mm, aspect ratio ~1:1.4142).
   - The reader viewport provides container scaling without distorting content typography or visual anchors.

4. **Reader Ad Boundary**:
   - Advertisements must NEVER be rendered inside reading pages. Ads belong exclusively in website discovery and browsing zones (`home_banner`, `home_sidebar`, `saved_banner`, `saved_sidebar`).

5. **Icon Semantic Fidelity**:
   - Book icons are resolved via `lib/vasuki/icon-map.ts` using `lucide-react` without arbitrary emojis.
